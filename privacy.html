Privacy Policy

Last updated: 01.10.2026

TikTokLike ("the app") is a desktop program that runs only on the computer of the person who uses it ("the user"). It has no server and no database operated by its author.

What the app accesses

  • TikTok account data, with the user's consent via TikTok Login Kit: the account's open ID and display name (scope user.info.basic) and the permission to upload videos to that account (Content Posting API scopes the user approves).
  • The user's own video files that the user selects or creates with the app.

What is stored and where

The access and refresh tokens issued by TikTok are saved in a configuration file on the user's own computer. They are used only to call TikTok's API on behalf of the user and are never sent anywhere else. Videos, captions and the posting history stay in folders on the user's computer.

Sharing and selling

The app does not collect, share, sell or transmit personal data to the author or to any third party. Data goes only between the user's computer and TikTok, for the purpose of publishing the user's own videos.

Control and deletion

The user can revoke the app's access at any time in TikTok (Settings and privacy → Security & permissions → Apps and services) and can delete all stored tokens by deleting the app's configuration file. Uninstalling the app removes everything it stored.
